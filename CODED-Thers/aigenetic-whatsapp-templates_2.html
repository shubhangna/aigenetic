Number save karwana

Stage 3 ke saath contact card bhejiye — "save kar lijiye" likhne se doctor ko manually type karna padta hai. Download AiGenetic.vcf → WhatsApp mein attach → Contact.

Language kaunsi chunein

Lead jis language mein enquiry kare, usi mein reply. Devanagari naam ya Hindi enquiry → हिंदी। Metro + English form → English. Baaki sab → Hinglish.

API template approval

Stage 1 first-contact hai — WhatsApp Business API par utility template approval chahiye. Stage 2 aur 3 lead ke reply ke baad 24-hour window mein free-form ja sakte hain.

Date apne aap

Date har baar aaj ki tareekh se bhar jaati hai, aur card ki bhaasha ke hisaab se — Hindi cards mein "24 अगस्त, सोमवार", English cards mein "24 August, Monday". Chip badal dijiye ya khud type kar dijiye.
