Why "most tests failing"

Not a site defect. Root cause: tests were run without HEADLESS=true, so Playwright launched a headed (visible) Chromium. In this sandbox (no real display focus), headed clicks on healthcare.html's calendar modal / audio player / live-call button / WhatsApp CTA don't register reliably, which cascades into timeouts for every subTest after the first click failure. Reproduced on both local (localhost:8989) and live (https://aigenetic.in) — same 4 subTest failures either way, confirming it's an execution-mode issue, not a remote-site-only issue.

ModeResult
HEADLESS=true (headless)10 passed, 0 failed
default (headed, HEADLESS unset)4 subTests failed (calendar close, audio playing class, live-call text, whatsapp request)

How to run correctly

HEADLESS=true python -m pytest tests/ --site remote     # live site
HEADLESS=true python -m pytest tests/ --site local       # localhost:8989, server must be running

--site only works via pytest (it's a conftest.py plugin option) — running a test file directly with python tests/test_healthcare.py uses unittest's own arg parser and doesn't know --site; set BASE_URL env var directly for that path instead.
